The meme picture was made by the agent in the session that built this entry; the entry itself is the X post that carries it, posted from a public account with @_myronera tagged and a make.fun play code in its text. Places go by the post's likes + reposts + quotes.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
